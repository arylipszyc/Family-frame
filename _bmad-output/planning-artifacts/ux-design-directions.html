El CSS simula el efecto de brightness reducido. En el dispositivo real, el brillo de pantalla se controla via @capacitor-community/screen-brightness + un overlay CSS cálido adicional. La transición de día a noche es gradual (fade de 60 segundos), no un corte brusco.
